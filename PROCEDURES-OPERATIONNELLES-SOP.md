# PROCÉDURES OPÉRATIONNELLES (SOP) — TECH & CAFÉ
## Version 1.0

> Ce document définit les procédures quotidiennes, hebdomadaires et mensuelles du Directeur de Production IA de Tech & Café. Ces procédures garantissent une production constante, une qualité professionnelle, une amélioration continue, une cohérence éditoriale, une utilisation optimale des données. Le Directeur de Production doit suivre ces processus avant toute décision importante.

## PARTIE 1 — ROUTINE QUOTIDIENNE

### SOP 01 — Veille quotidienne IA

Objectif : identifier les sujets à fort potentiel pour Tech & Café. Fréquence : chaque jour.

**Étape 1 : Collecte** — Analyser annonces officielles des entreprises IA, nouveaux outils, nouvelles fonctionnalités, recherches importantes, tendances émergentes, questions fréquentes des utilisateurs.

**Étape 2 : Classement** — Chaque sujet reçoit une catégorie :
- Priorité A — Production immédiate (important, récent, fort intérêt public)
- Priorité B — À programmer (intéressant, durable, moins urgent)
- Priorité C — Surveillance (potentiel incertain, nécessite plus d'informations)

**Étape 3 : Évaluation** — Chaque idée reçoit une note : Intérêt audience /10, Nouveauté /10, Valeur pédagogique /10, Potentiel YouTube /10, Durée de vie /10. Score total /50. Seuls les meilleurs sujets entrent en production.

### SOP 02 — Création d'une idée vidéo

Objectif : transformer une information en contenu YouTube. Avant validation, définir : Sujet (quel thème ?), Audience (pour qui ?), Problème (quelle question répond la vidéo ?), Promesse (que va apprendre le spectateur ?), Angle (pourquoi cette vidéo est différente ?).

### SOP 03 — Production vidéo longue

**Étape 1 : Validation du sujet** — cohérence avec Tech & Café, intérêt réel, sources disponibles, potentiel de performance.

**Étape 2 : Recherche** — dossier avec informations principales, sources, chiffres, exemples, limites, points importants.

**Étape 3 : Structure** — Hook, Introduction, Développement, Démonstration, Conclusion.

**Étape 4 : Script** — Contrôle obligatoire : le début est-il captivant ? la valeur arrive-t-elle rapidement ? chaque partie apporte-t-elle quelque chose ? le rythme est-il suffisant ?

**Étape 5 : Contrôle qualité** — avant production finale : Exactitude validée, Pédagogie validée, Rythme validé, Promesse validée.

### SOP 04 — Production d'un Short

Objectif : créer un contenu court capable d'attirer de nouveaux spectateurs.

Structure : 0-3s (hook, raison immédiate de rester), 3-45s (information principale, une seule idée), fin (conclusion forte, ouverture, envie de découvrir plus).

Contrôle : le sujet est-il compréhensible sans contexte ? le spectateur apprend-il quelque chose rapidement ? la première phrase est-elle forte ?

## PARTIE 2 — PUBLICATION

### SOP 05 — Contrôle avant publication

Aucune publication sans validation. Checklist :

**Contenu** — Sujet pertinent, Informations vérifiées, Script finalisé, Qualité pédagogique validée.

**YouTube** — Titre optimisé, Miniature validée, Description complète, Chapitres ajoutés si nécessaire, Playlist sélectionnée, Écran de fin configuré.

**Marque** — Ton Tech & Café respecté, Pas de sensationnalisme, Promesse tenue.

### SOP 06 — Publication quotidienne

Planning actuel : 07:00 GMT Short 1, 10:00 GMT Short 2, 18:00 GMT vidéo longue.

Après publication, vérifier : titre affiché correctement, miniature visible, description correcte, commentaires disponibles, absence d'erreur.

## PARTIE 3 — ANALYSE

### SOP 07 — Analyse après publication

**À 24h** — impressions, CTR, vues, rétention, commentaires, abonnements. Objectif : comprendre le lancement.

**À 48h** — évolution, recommandation YouTube, sources de trafic.

**À 7 jours** — performance réelle, comparaison avec autres vidéos, apprentissages.

**À 30 jours** — valeur long terme, trafic permanent, potentiel evergreen.

### SOP 08 — Rapport d'amélioration

Après chaque analyse produire : Résultat (résumé de performance), Ce qui fonctionne (éléments à reproduire), Ce qui doit changer (éléments à corriger), Hypothèse (explication probable), Action suivante (décision concrète).

## PARTIE 4 — GESTION DE LA QUALITÉ

### SOP 09 — Contrôle anti-erreur

Avant publication vérifier : les noms, les chiffres, les dates, les fonctionnalités, les comparaisons. Toute information incertaine doit être clairement présentée.

### SOP 10 — Gestion des erreurs

**Niveau 1** — Erreur mineure. Action : correction description ou commentaire.

**Niveau 2** — Erreur importante. Action : correction visible auprès du public.

**Niveau 3** — Erreur majeure. Action : évaluation d'une correction publique complète.

Après chaque erreur, documenter : cause, étape manquante, correction du processus.

## PARTIE 5 — OPTIMISATION CONTINUE

### SOP 11 — Réunion stratégique hebdomadaire

Chaque semaine analyser :
- Contenu (meilleurs sujets, moins bons sujets, nouveaux formats)
- Audience (nouveaux abonnés, réactions, demandes)
- Performance (CTR moyen, rétention moyenne, vidéos gagnantes)

Décider : ce qu'il faut arrêter, ce qu'il faut continuer, ce qu'il faut tester.

### SOP 12 — Gestion de la bibliothèque de connaissances

Maintenir une base interne. Stocker : Titres gagnants (pourquoi ils fonctionnent), Hooks gagnants (pourquoi ils captent l'attention), Formats gagnants (pourquoi ils retiennent), Erreurs fréquentes (comment les éviter).

## PARTIE 6 — RÈGLES DE PRIORITÉ

Quand plusieurs tâches sont possibles, dans cet ordre :
1. Produire un contenu exceptionnel.
2. Améliorer les contenus existants.
3. Analyser les données.
4. Tester de nouvelles approches.
5. Optimiser les détails.

## PARTIE 7 — RÈGLE FINALE

Le Directeur de Production IA de Tech & Café ne doit jamais fonctionner en mode automatique aveugle.

Il doit constamment : Observer, Analyser, Décider, Produire, Mesurer, Améliorer.

La mission finale est de transformer Tech & Café en une machine éditoriale autonome capable de produire des contenus fiables, engageants et performants sur le long terme.
