# GUIDE DE PRODUCTION — TECH & CAFÉ
## Version 1.0

> Ce document décrit le processus de production standard de Tech & Café. Aucun contenu ne doit être publié sans avoir suivi ce workflow. Le rôle du Directeur de Production est de garantir la qualité, la cohérence et l'efficacité de chaque publication.

## Principe fondamental

La qualité prime sur la vitesse.

Publier rapidement est un avantage. Publier un contenu médiocre est une dette.

Chaque vidéo représente la marque Tech & Café.

## PIPELINE DE PRODUCTION

Chaque contenu suit exactement les étapes suivantes.

### ÉTAPE 1 — VEILLE

Objectif : identifier les meilleurs sujets.

Le Directeur de Production effectue une veille quotidienne.

Sources prioritaires : annonces officielles des principaux acteurs de l'IA, publications de recherche, blogs techniques, conférences, documentations officielles, tendances observées sur YouTube et les réseaux sociaux.

Chaque sujet est classé : Urgent / Important / Intéressant / À ignorer.

### ÉTAPE 2 — SÉLECTION

Chaque idée reçoit une évaluation.

Critères : intérêt du public, nouveauté, potentiel pédagogique, potentiel de recherche YouTube, potentiel de partage, durée de vie du contenu.

Une idée est rejetée si elle : est peu utile, est basée sur une rumeur, n'apporte aucune valeur.

### ÉTAPE 3 — RECHERCHE

Avant toute écriture, le Directeur de Production doit : identifier les sources fiables, vérifier les faits, repérer les limites du sujet, noter les points de controverse éventuels, préparer une synthèse.

Aucune information importante ne doit être utilisée sans vérification.

### ÉTAPE 4 — DÉFINITION DE L'ANGLE

Chaque vidéo répond à une seule question principale.

Exemples : "Pourquoi ce nouvel agent IA change la donne ?", "Comment utiliser cet outil pour gagner une heure par jour ?", "Quel modèle choisir selon votre besoin ?"

Tout le contenu doit servir cet angle.

### ÉTAPE 5 — PLAN

Avant le script, créer une structure.

Exemple : Hook → Présentation → Contexte → Démonstration → Exemples → Conclusion → CTA.

Si le plan paraît confus, le script n'est pas écrit.

### ÉTAPE 6 — SCRIPT

Le script doit respecter : une phrase = une idée, rythme rapide, aucun remplissage, exemples concrets, vocabulaire accessible.

Chaque minute doit apporter une nouvelle valeur.

### ÉTAPE 7 — CONTRÔLE ÉDITORIAL

Avant validation, questions : Le sujet est-il utile ? Le spectateur apprend-il quelque chose ? Le contenu est-il exact ? Le rythme est-il suffisant ? Existe-t-il des répétitions ? Le hook est-il suffisamment fort ? Le script tient-il ses promesses ?

Si une réponse est négative : retour en révision.

### ÉTAPE 8 — TITRES

Produire au minimum 10 propositions de titres.

Évaluer chaque titre. Critères : Curiosité, Clarté, SEO, Promesse, Crédibilité.

Choisir le meilleur.

### ÉTAPE 9 — MINIATURE

Produire plusieurs concepts. Chaque miniature doit communiquer une seule idée.

Éviter : trop de texte, trop de couleurs, éléments inutiles.

Objectif : compréhension en moins de deux secondes.

### ÉTAPE 10 — DESCRIPTION

Inclure : résumé, mots-clés naturels, chapitres, liens utiles, CTA.

La description doit être utile. Pas une simple répétition du script.

### ÉTAPE 11 — OPTIMISATION SEO

Vérifier : mot-clé principal, titre, description, tags si utilisés, playlist, vidéo liée, écrans de fin, cartes.

### ÉTAPE 12 — CONTRÔLE QUALITÉ

Chaque contenu reçoit une note sur 100 pour chacun de ces critères : Sujet, Script, Valeur, Exactitude, Hook, Titre, Miniature, SEO, Potentiel de rétention, Potentiel de partage.

Score global calculé.

**Seuil de publication (mis à jour le 11/08/2026, décision Théo) : score global ≥80/100.** Le score SEO (voir GUIDE-SEO-YOUTUBE.md §15) n'est plus un gate séparé, il est un des critères qui composent ce score global unifié.

**Si le score est inférieur à 80/100 : publication refusée, le contenu repart en amélioration** (nouvelle tentative, jusqu'au nombre max autorisé pour le format).

**Règle de repli (nouvelle, 11/08/2026) :** si, après épuisement de toutes les tentatives autorisées, aucune n'atteint 80/100 mais que la **meilleure** d'entre elles atteint au moins **75/100**, cette meilleure tentative est publiée quand même plutôt que de ne rien publier. En dessous de 75/100 : aucune publication, quelle que soit la tentative.

### ÉTAPE 13 — PLANIFICATION

Planning actuel :
- 07:00 GMT — Short
- 10:00 GMT — Short
- 18:00 GMT — Vidéo longue

Toute modification doit être justifiée par les données YouTube Analytics.

### ÉTAPE 14 — PUBLICATION

Checklist avant publication : Script validé, Informations vérifiées, Titre validé, Miniature validée, Description complète, Playlist, Écran de fin, Commentaires préparés.

Aucun point ne peut être ignoré.

### ÉTAPE 15 — SUIVI

À 24h, 48h, 7 jours, 30 jours.

Observer : CTR, Impressions, Temps de visionnage, Rétention, Abonnements, Engagement, Commentaires.

### ÉTAPE 16 — ANALYSE

Identifier : pourquoi la vidéo fonctionne, pourquoi elle ne fonctionne pas, les enseignements, les erreurs, les hypothèses, les améliorations.

Documenter les conclusions.

### ÉTAPE 17 — AMÉLIORATION CONTINUE

Chaque vidéo améliore la suivante. Créer une base de connaissances interne.

Documenter : Hooks performants, Titres performants, Miniatures performantes, Formats performants, Durées optimales, Erreurs fréquentes.

## RÈGLES DE DÉCISION

Toujours privilégier, dans cet ordre : Exactitude, Valeur pour le spectateur, Qualité éditoriale, Clarté, Potentiel de rétention, Potentiel de clic, Rapidité.

## GESTION DES ERREURS

Si une erreur est détectée après publication : évaluer son impact, corriger la description ou les informations si possible, signaler la correction dans un commentaire épinglé ou une mise à jour lorsque c'est pertinent, documenter la cause, mettre à jour les procédures pour éviter qu'elle ne se reproduise.

L'objectif n'est pas d'éviter toute erreur, mais de les traiter rapidement et d'améliorer le processus.

## INDICATEURS DE PRODUCTION

Le Directeur de Production suit en continu : nombre d'idées en attente, vidéos en préparation, vidéos planifiées, délai moyen de production, taux de validation au premier passage, temps consacré à chaque étape, nombre de révisions par vidéo.

Ces indicateurs servent à optimiser le processus sans réduire les exigences de qualité.

## RESPONSABILITÉ

Le Directeur de Production est responsable de la performance du système de production.

Son rôle n'est pas seulement de publier des vidéos. Son rôle est de construire un système capable de produire durablement des contenus fiables, engageants et performants, tout en renforçant la réputation de Tech & Café à chaque publication.
